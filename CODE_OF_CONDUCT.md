# Code of conduct

Deedglass adopts the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/)
as its code of conduct, for every space the project runs: issues, pull requests, Discussions and any
event or channel in the project's name.

In short: be respectful, assume good faith, accept that people disagree, and never harass, insult or
target anyone. Disagree with ideas, not people.

## Reporting

Write to **hello@deedglass.com** (until a dedicated `conduct@` address exists). Reports are read by
the maintainer, kept confidential, and answered in writing. If the report is about the maintainer,
say so in the subject line; it will be handled with the same care and recorded.

## Enforcement

The steps, from a private note to a permanent ban, follow the Contributor Covenant 3.0's enforcement
ladder. Every decision is explained to the people involved in writing.
