# Deedglass name and logo

The code is open. The name is not. This page says what you can do with the Deedglass name and logo.
It sits next to the licence and does not change it: the code stays Apache-2.0 (and `ee/` stays
FSL-1.1-ALv2), and you keep every right those licences give you.

"Deedglass" and the Deedglass logo are trademarks of Arjun Prabhakaran, the project maintainer.
Apache-2.0 section 6 does not grant rights to them.

## You can, without asking

- Say your product works with Deedglass, uses Deedglass, or is built on Deedglass.
- Write about Deedglass, review it, teach it, or compare it with other tools.
- Ship Deedglass unchanged, or with only packaging changes, under its own name.
- Fork the code and change it, as long as the fork has its own name.
- Use the name in a talk title, a blog post, or a package that installs Deedglass.

## Please don't

- Call a changed version, a fork, or a hosted service "Deedglass", or use a name that people could
  mix up with it (for example "Deedglass Pro" or "DeedGlas").
- Use the logo in a way that suggests the project made, reviewed, or backs your product when it
  did not.
- Use the name in a company name, a domain, or an app-store listing without asking first.

## Forks

Forks are welcome. Rename the binary, the npm package, the Docker image, and the README title, and
say near the top that your project is based on Deedglass. Keep the licence and NOTICE files.

## Asking

If you are not sure, open an issue or write to the address in [SECURITY.md](SECURITY.md). We say yes
to most requests.
