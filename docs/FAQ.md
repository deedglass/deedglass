# FAQ

Short answers to the questions people ask first. **Owner: S33**, which writes the answers for the docs site. This page is a stub.

## Questions S33 will answer

- How is this different from logging what the agent asked for?
- Does my agent ever see my database password or API tokens?
- What do L0, L1 and L2 mean, and which connectors reach which level?
- Can someone check a deed without trusting Deedglass?
- What happens when Deedglass cannot tell whether a tool ran?
- Why not an outbox plus Debezium, a TEE, zkTLS, database ledger tables or CloudTrail?
- What does Stop do, and how fast?
- Does Insights change my policies by itself?
- Can I run it myself?

## What this page does not do

It does not answer yet. Each answer lands with the session that builds the feature, and S33 collects them.
