# Cursor marketplace listing kit

The founder submits this through Cursor's own process (form, PR or publisher account, as Cursor's
docs say on the day). Claude prepares files only.

- `listing.json`: name, tagline (80 characters at most), description (300 at most), the install
  deeplink generated by `internal/installlinks`, links, and the icon's source and sha256.
- `icon-512.png`: copied byte for byte from the site's approved icon (`site/public/icon-512.png`).
- `screenshot-1-play.png`: deedglass.com/play, scene 2, 1440 px dark. Two more are pending, captured
  by the founder in Cursor: a scan result in the terminal and a Gate deny in the MCP panel.

## What the listing installs

`npx -y deedglass mcp serve`, Deedglass's MCP server. It reads the key `npx deedglass init` wrote,
or `DEEDGLASS_API_KEY`.

## What it doesn't do

No telemetry. No key or server credential in the link. It doesn't change any other MCP server you
have; putting a server behind Deedglass is your explicit `deedglass mcp wrap` step.
