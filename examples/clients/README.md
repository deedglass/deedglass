# MCP client config for Deedglass

Generated by `deedglass mcp snippet` (`go generate ./internal/mcp/snippet`) and pinned by the
goldens in `internal/mcp/snippet`. Paths use `/Users/you/…`: run `deedglass mcp snippet` on your
machine for your own absolute paths. Replace `dg_test_REPLACE_ME` with your agent's key.

**Wrapping a stdio server** (`deedglass mcp wrap`, S14):

| File | Client | Where it goes |
|---|---|---|
| `claude-desktop.json` | Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` |
| `claude-code.sh` | Claude Code | run it in a terminal |
| `cursor.json` | Cursor | `~/.cursor/mcp.json` or `.cursor/mcp.json` |
| `vscode.json` | VS Code | `.vscode/mcp.json` |
| `windsurf.json` | Windsurf | `~/.codeium/windsurf/mcp_config.json` (Devin Desktop: `~/.config/devin/mcp_config.json`) |

**The Gate's own endpoints over HTTP** (`--transport http`, S15): `http-claude-code.sh`,
`http-cursor.json`, `http-vscode.json` (prompts for the key; none in the file), `http-windsurf.json`,
and `http-claude-desktop.json`, which runs `deedglass mcp serve` (Claude Desktop's remote
connectors can't reach `127.0.0.1`).

The Acme demo's four-entry config is in `examples/demo/clients/` (`make demo-snippet`).

See `docs/MCP_CLIENTS.md`.
