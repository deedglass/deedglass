Show your grade in your README. You add it; we never do.

**Before you start**

- A scan you're happy to show: [Scan in 60 seconds](/get-started/scan/).
- A public GitHub repository, so shields.io can read the file.

## 1. Write the badge file

```sh test title="Terminal"
$ npx -y deedglass scan --badge --no-write
…
[![agent blast radius](https://img.shields.io/endpoint?url=https%3A%2F%2Fraw.githubusercontent.com%2F…%2F.deedglass%2Fscore.json)](https://deedglass.com/score)
```

`--badge` writes `.deedglass/score.json`, a shields.io endpoint file such as `{"schemaVersion":1,"label":"agent blast radius","message":"C","color":"3F4453","cacheSeconds":3600}`, and prints the Markdown line for your README. With a GitHub remote, the line has your owner, repo and branch filled in; without one, it has placeholders to replace.

## 2. Commit it yourself

`deedglass init` writes `.deedglass/*` and `!.deedglass/score.json` to `.gitignore`: keys stay out of git and the badge file may go in. If your `.gitignore` has an older `.deedglass/` line, the scan prints the two lines to use instead.

```sh test=skip reason="writes to your git history"
git add .deedglass/score.json
git commit -m "Add the Deedglass blast-radius badge"
```

Paste the printed line into your README and push. shields.io reads your own file, and caches it, so a new grade can take a few minutes to show. The badge links to `deedglass.com/score`, which explains what the grade means.

## Link the badge to your own result (optional)

`--badge-share` does the same, but the badge links to your `/s` share page instead of `deedglass.com/score`, and the scan prints a warning: anyone who reads your README can open that page. Its link holds the grade, the points and how many findings of each severity, and nothing else: no finding ids or deduction ids, because a README is public and those would tell a reader where to look. The link keeps the result of that run, so run `--badge-share` again when the grade changes.

## Share a result without a badge

`deedglass scan --share` prints a link, `https://deedglass.com/s#v1.…`. Everything after `#` stays in the browser: no server receives it. The link holds only the grade, the points, the finding counts, the finding ids and the deduction ids, never a path, a table, a host or a variable name.

## What it doesn't do

<Limits>
- Deedglass never adds a badge to anyone's repo, and never opens a pull request, issue or comment to suggest one.
- The scan never runs git. Committing the file is your step.
- A grade is a snapshot of one machine's setup when you ran the scan. Run it again after you change your configs.
</Limits>
