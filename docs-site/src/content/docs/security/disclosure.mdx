---
title: Responsible disclosure
description: How to report a security issue in Deedglass privately while the full policy is being written.
lastVerified: "2026-10-05"
---

If you find a security issue in Deedglass, tell us privately first. Please don't open a public issue.

- **Email:** `security@deedglass.com`. The address is being set up; the full policy below confirms it is live.
- **Include:** what you found, how to reproduce it, the version (`deedglass version`), and what an attacker could do with it.
- **Please** test only against your own org and your own stack, and stop and tell us if you see anyone else's data.

:::note[Being written]
The full policy (what to expect after you report, scope, safe harbour and supported versions) is written in the security pass before launch and replaces this note.
:::
