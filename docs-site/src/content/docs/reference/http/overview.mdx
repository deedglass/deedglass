The API is JSON over HTTPS under `/v1`. Every endpoint is in the [endpoint reference](/reference/api/), generated from `api/openapi.yaml`, the same file a test keeps equal to the server's routes.

## Conventions

- **Objects** carry `"object": "<type>"` and an `"id"` with a prefix: `act_`, `deed_`, `agt_`, `pol_`, … ([Ids](/reference/ids/)). Ids are lowercase.
- **Timestamps** are RFC 3339 in UTC.
- **Money** is `amount` in minor units (an integer) plus `currency` (ISO 4217, lowercase): `{"amount": 12000, "currency": "usd"}` is $120.00.
- **Every response** carries `Deedglass-Request-Id` and the `Deedglass-Version` it was answered with.
- **CORS** is closed, except for the public key set and the MCP protected-resource metadata.

## Errors

Every error has the same envelope and a page of its own:
