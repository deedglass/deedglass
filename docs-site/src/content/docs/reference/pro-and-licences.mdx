Every Deedglass feature is free while we grow. This page says what that covers and how the licence path is kept for later.

## Every feature is free while we grow

Every Deedglass feature is free to use, with no licence key: Gate, Witness, deeds, Stop, Undo, Insights, `scan` and `scan --full`, every policy pack, one-step session undo, the security review pack and the agency view. Nothing reads a licence and nothing calls a licence server.

We plan to introduce paid options for teams and a hosted service later, after Deedglass reaches about 100,000 users. Anything free today stays free for people who run Deedglass themselves.

## The licence path, kept for later

The commands below stay in the CLI so a later paid option can ask for a key without a rewrite. You don't need them today.

### Activate a licence

```sh test=skip reason="licences ship in S48"
deedglass licence activate <key>
deedglass licence show
```

The key arrives by email from Dodo, our payment provider and reseller, and on the return page. The CLI activates the key with Dodo, then our server checks it again and returns a signed record, saved to `.deedglass/licence.json` (mode 0600; `DEEDGLASS_LICENCE_FILE` moves it). `deedglass licence refresh` and `deedglass licence deactivate` do what they say.

### Offline and grace

Every feature is free while we grow, so nothing checks a licence and nothing is sent to deedglass.com: the scan reads files on your machine and, with `--postgres-dsn-env`, connects only to the database you name. The `deedglass licence` commands, kept for a later paid option, are the only ones that call Dodo Payments or deedglass.com, and only when you run them; `DEEDGLASS_NO_NETWORK=1` stops those calls. `deedglass version --check` and the `--latest` option of `deedglass policy install` and `policy packs` contact GitHub when you use them. Head timestamps are off by default; with TSAs or a transparency service listed in deedglass.yaml, `deedglass deeds timestamp` and each export contact only those.

`licence.clock` sits next to `.deedglass/licence.json`. Offline, Pro keeps working for up to **14 days** after the last successful check. After that, Pro is read-only: existing full reports open, installed Pro packs keep enforcing, and `scan --full` refuses. The exact line:

```text
Pro paused: your licence was last checked 15 days ago. Run deedglass licence refresh. Everything free still works.
```

On a private repo with a licence set, the scan Action checks it online on every run: it activates the key with Dodo Payments and deedglass.com, reads it back offline, and frees the activation with Dodo Payments at the end. Without a licence that includes the comment, it adds no new comment and its job summary says why.

## Free features never read the licence

No network call and no telemetry. The free test suite passes with an expired, corrupt or missing licence.

## Licence of the code

The core, SDKs, CLI and the Action are Apache-2.0. The features in `ee/` are free to use and stay under FSL-1.1-ALv2; each release becomes Apache-2.0 after two years.

## What it doesn't do

<Limits>
- A lapsed licence never weakens a policy that is already enforcing.
- No seat counting, no usage metering, no telemetry.
</Limits>
