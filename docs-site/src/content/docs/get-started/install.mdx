Add Deedglass to Cursor, VS Code, LM Studio, Goose, Claude Code or Claude Desktop in one step.

**Before you start**

- Node 22.12 or later: every client runs the server with `npx -y deedglass mcp serve`.
- An agent key in `DEEDGLASS_API_KEY`, and `DEEDGLASS_SERVER` if your server isn't on `127.0.0.1:8080`.

## One step per client

Every link and command below adds the same server object, `{"command":"npx","args":["-y","deedglass","mcp","serve"]}`. They are generated at build time, never typed by hand.

<InstallTable />

## Registries

Deedglass is listed in the Official MCP Registry as `io.github.deedglass/deedglass`, on Glama, and in the Docker MCP Catalog.

## Prefer the HTTP gateway?

These installs run the stdio bridge. To connect a client straight to the server's HTTP endpoint, see [Connect Claude Code](/get-started/claude-code/), [Connect Claude Desktop](/get-started/claude-desktop/) and [Connect Cursor, VS Code and Windsurf](/get-started/cursor-vscode-windsurf/).

## Check it

```sh test=skip reason="install links ship in S47"
claude mcp list
```

`deedglass` is listed and connected.

## What it doesn't do

<Limits>
- A one-click install adds the server to your client. It doesn't create a key or a policy.
- The client asks you to confirm before it adds a server. Nothing installs silently.
</Limits>
