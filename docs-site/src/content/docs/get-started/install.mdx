Add Deedglass to Cursor, VS Code, LM Studio, Goose, Claude Code, Claude Desktop or Windsurf in one step.

**Before you start**

- Run `npx deedglass init` in a terminal once. It starts a local Deedglass server and writes the agent key every client below uses, so no link holds a key.
- Node 18 or later for the `npx` installs. The Claude Desktop bundle carries its own binary and needs no Node.

## One step per client

Every link and command below adds the same server, `{"command":"npx","args":["-y","deedglass","mcp","serve"]}`. They are generated from one Go package at build time, never typed by hand, and a test decodes each one back to that server and checks that it holds no key.

<InstallTable />

`deedglass mcp install-links` prints the same list in your terminal.

## Claude Desktop

Claude Desktop can install a `.mcpb` bundle, but the bundles aren't attached to a release yet. Until they are, add the bridge by hand: [Connect Claude Desktop](/get-started/claude-desktop/). From a checkout, `make mcpb` builds the three bundles (macOS Apple silicon, macOS Intel and Windows) into `.tmp/mcpb`; opening one, Claude Desktop asks for two optional settings: an agent key (kept as a secret) and the server address, which defaults to `http://127.0.0.1:8080`. Leave the key empty to use the one `deedglass init` wrote. The bundles are not code-signed yet, so Claude Desktop says so when you open one.

## Registries

The server's registry name is `io.github.deedglass/deedglass`, the same in the npm package and the container image label.

## Prefer the HTTP gateway?

These installs run the stdio bridge. To connect a client straight to the server's HTTP endpoint, see [Connect Claude Code](/get-started/claude-code/), [Connect Claude Desktop](/get-started/claude-desktop/) and [Connect Cursor, VS Code and Windsurf](/get-started/cursor-vscode-windsurf/).

## Check it

```sh test=skip reason="needs Claude Code on your machine"
claude mcp list
```

`deedglass` is listed and connected, even before `init`: with no key found it lists its tools, sends nothing, and answers every call with what to run. Its log says the same: `No Deedglass key found. Run npx deedglass init in a terminal, then restart your MCP client.`

## What it doesn't do

<Limits>
- A one-click install adds the server to your client. It doesn't create a key or a policy.
- The client asks you to confirm before it adds a server. Nothing installs silently.
</Limits>
