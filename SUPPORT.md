# Getting help

| You want to | Go to |
|---|---|
| Ask a question or share what you built | GitHub Discussions (the **Q&A** and **I ran it** categories) |
| Report a bug | an issue, with the **Bug** form (version, install method, steps, logs with secrets removed) |
| Tell us how a first run went | an issue, with the **I ran it** form |
| Report a vulnerability | **security@deedglass.com**, never a public issue ([`SECURITY.md`](SECURITY.md)) |
| Read the docs | [docs.deedglass.com](https://docs.deedglass.com) |

## Response times

Deedglass is maintained by one person. Replies are best effort, usually within two business days.
Security reports are acknowledged first. There is no phone or call support.

## Before you ask

`deedglass doctor` checks a local install and prints a fix for each problem. `deedglass version`
gives the version and commit to include in a bug report.
